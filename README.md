### 5. Піднести до кубу всі елементи даного одновимірного масиву. Виконати сортування елементів масиву за спаданням, використовуючи метод обміну.
```javascript
A = [4, -2, 7, 1, 3]
print("Початковий масив:", A)

for i in range(len(A)):
    A[i] = A[i] ** 3
print("Масив після піднесення до куба:", A)

n = len(A)

for i in range(n - 1):
    for j in range(n - 1 - i):
        if A[j] < A[j + 1]:
            A[j], A[j + 1] = A[j + 1], A[j]
print("Масив за спаданням:", A)
```
